Engineering Portfolio

Three projects, three stages of maturity

Each project below is labelled by what it actually is right now — a deployed system, a live demo, or a documented learning exercise — rather than overstating any of them.

Production-Tested

Palm Fruit Ripeness Classification System

Trained and benchmarked five CNN architectures (MobileNetV2, MobileNetV3, EfficientNetB0, ShuffleNetV2, ResNet18) for on-device ripeness classification, selecting MobileNetV2 for the best accuracy-to-latency tradeoff. Deployed as real-time edge inference on a Raspberry Pi 4B. The system also includes a FastAPI serving layer, Prometheus observability, a Grafana dashboard, and Terraform-provisioned cloud infrastructure — built and CI-tested, with cloud deployment applied on demand rather than run continuously.

  • Python
  • TensorFlow / PyTorch
  • TFLite
  • FastAPI
  • Docker
  • Prometheus + Grafana
  • Terraform

Deployed Demo

PPE Compliance Detection System

Quantised a YOLOv8n model to INT8 ONNX for real-time detection across 14 personal protective equipment classes (mAP@50: 0.776). Served through a Gradio interface with dual-backend inference — local ONNX by default, with automatic fallback to a serverless API — and deployed live on Hugging Face Spaces with a CI pipeline validating the exported model artifact on every push.

  • YOLOv8
  • ONNX Runtime
  • Gradio
  • OpenCV
  • GitHub Actions
